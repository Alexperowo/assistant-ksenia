# Assistant Ksenia — состояние работ на 8 сентября 2026

Этот файл находится рядом с исходным кодом как короткая передача проекта. Он не
заменяет `AGENTS.md`, `docs/AUDIT.md`, `docs/ROADMAP.md` и текущий
`runtime/audit/latest.txt`; при расхождении приоритет у кода и свежего аудита.

## Что выполнено и сохранено в Git

1. Сохранение диалога после управляемых ошибок модели: очистка устаревшего
   подтверждения/голосового статуса, следующий вопрос продолжает разговор.
2. Исследование: типизированы отказ поиска/запрет/требование подтверждения/
   отсутствие источников; лишний retry после ошибки не выполняется, частичный
   успех сохраняется.
3. Read-only browser worker: checkpoint проходит внутрь ожидания; private Windows
   Job Object убирает только собственное дерево worker/Chromium при отмене,
   timeout и штатном выходе. Это не sandbox.
4. DNS страницы: admission `open` перенесён внутрь управляемого worker; private,
   mixed, file, credential и ошибочный DNS отвергаются до Chromium.
5. LLM transport: `complete_chat` с checkpoint проверяет отмену до отправки и
   во время HTTP headers, не ждёт тело HTTP-ошибки; есть native loopback tests
   fragmented headers/body/cancel. Это не полная миграция всех HTTP-клиентов.
6. Общий research budget: 60/180/600 секунд для fast/normal/deep в
   `routing.research_timeout_seconds`; один monotonic deadline для planning,
   search, read, synthesis и verification. Он не сохраняет поздний ответ и
   не закрывает диалог.
7. Runtime smoke: проверка активной модели всегда использует прямой режим без
   thinking, поэтому исследовательская модель не расходует короткий smoke на
   внутреннее рассуждение.

## Как продолжать

1. Прочитать `AGENTS.md`, затем `docs/AUDIT.md`, `docs/ROADMAP.md` и
   `docs/HANDOFF.md`.
2. Проверить `git status`, не менять `config/user.json`, `runtime`, модели или
   workspace без отдельной причины.
3. Перед этапом — тест/инвариант; после — `scripts/check.ps1`, обновление
   документации, checkpoint в `runtime/audit/checkpoints` и отдельный commit.
4. Не объявлять skipped/disabled feature проверенной.
