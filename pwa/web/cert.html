Подключить планшет к Ксении

Один раз нужно установить сертификат Ксении — без него браузер не даст включить микрофон.

1. Скачать сертификат Ксении
  1. Откройте «Настройки» планшета. В поиске настроек напишите «сертификат».
  2. Выберите «Установить из памяти устройства» (или «Установка сертификатов»), затем «Сертификат ЦС».
  3. Согласитесь с предупреждением и выберите файл «ksenia-ca.crt» в папке «Загрузки».
  4. Вернитесь сюда и нажмите кнопку ниже.
5. Открыть Ксению
