# Состояние реализации

## Готово и проверено программно

- [x] Одна активная GGUF-модель, проверка владельца процесса и освобождения порта.
- [x] Четыре функциональные роли: дворецкий, исследователь, разработчик и тяжёлый мозг.
- [x] Gemma 12B для разговора, Qwopus 9B MTP для исследования/разработки, Gemma 26B-A4B для сложного плана.
- [x] Контекст 64K, асимметричный KV `Q8_0/Q5_0`, управляемые reasoning и длина ответа.
- [x] MTP A/B и русский агентный допуск Qwopus.
- [x] Сжатие истории с голосовыми статусами и совместимостью строгих chat templates.
- [x] Постоянная история, подтверждённые факты и передача памяти между ролями.
- [x] Гибридный RAG: FTS5, Qwen3-Embedding-0.6B на CPU, векторы, цитаты до строк и пропуск секретов.
- [x] Silero Xenia, произношение дат и чисел, защита начала Bluetooth-речи и SAPI-резерв.
- [x] Vosk для «Ксения слушай/стоп», faster-whisper Large v3 Turbo для команды.
- [x] Голосовая остановка задачи во время генерации и ограниченный retry микрофона.
- [x] Опциональная активация стандартной AVRCP-медиакнопкой JBL.
- [x] Долговечные задачи, пауза, продолжение, отмена и восстановление после аварии.
- [x] Подтверждения по области задачи и отдельные подтверждения удаления/отправки.
- [x] Разработка в `workspace`: чтение, поиск, запись, точечная замена, тесты, резервные копии и отмена.
- [x] Windows UI Automation, клавиатура и подтверждаемый резерв мыши.
- [x] Постоянный профиль Chromium, чтение страниц и подтверждаемые действия.
- [x] Безопасный общий поиск DuckDuckGo с Bing-резервом; Google News для свежих новостей.
- [x] Отдельный исследовательский маршрут с параллельным открытием и ограниченными доказательствами.
- [x] Структурированные цены, валюта, наличие, ссылки и время проверки.
- [x] Подготовка и отдельная подтверждаемая отправка сообщений; покупки и платежи запрещены.
- [x] Доступная LAN-панель с PIN, клавиатурой, паузой, отменой и подтверждением.
- [x] Единая безопасная диагностика и полный аудит.
- [x] Установщик закреплённых движков и моделей речи с подписями/хешами.
- [x] Полный комплект передачи проекта человеку или другой нейросети: `AGENTS.md`, архитектура, карта кода, конфигурация, данные, безопасность, тестирование, решения и журнал изменений.
- [x] Машинные lock-файлы Python/`llama.cpp`, аппаратные профили, проверка состояния без изменений и отчёт по реальному VRAM.
- [x] Чистый online-архив без LLM и личных данных, стадийное обновление `llama.cpp`, резервная копия и проверенный откат.
- [x] 191 автоматический тест, контроль количества и предупреждений, три случайных порядка, мутации 10/10, живые LLM, RAG, LAN и TTS → STT.
