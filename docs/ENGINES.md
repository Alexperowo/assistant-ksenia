# Движки, модели и настройки — для поиска ускорений

Всё, что запускает Ксению, кроме самих весов моделей и собранных программ. Цифры сняты 2026-10-09.

## Железо

- Процессор AMD Ryzen 5 3600 (6 ядер / 12 потоков), 46 ГБ памяти.
- GPU0 — RTX 5060 Ti 16 ГБ (Blackwell, sm_120): только мозг. Занято 14,4 из 16,3 ГБ.
- GPU1 — RTX 2080 Ti 22 ГБ (Turing, sm_75): голос, судья, слух. Занято 11,2 из 22,5 ГБ.
- Драйвер NVIDIA 610.57.04, CUDA в `/usr/local/cuda`. Ограничение мощности обеих карт — 155 Вт.
- Kubuntu 26.04, ядро Linux 7.0.

## Мозг — `ksenia-brain` :18100, GPU0

- Запуск: `brain/run_brain.sh` (все флаги там).
- Движок: форк llama.cpp от PrismML (`prism-b10754-2459f68`), нужен для формата PQ2_0 и MTP. Собран Release,
  CUDA, `CMAKE_CUDA_ARCHITECTURES=120`, `GGML_CUDA_FA=ON`, `GGML_CUDA_GRAPHS=ON`, `FA_ALL_QUANTS=OFF`.
- Модель: Ternary Bonsai 2 27B, `Bonsai-2-27B-PQ2_0-MTP.gguf` (7,6 ГБ) + зрение `mmproj-Q8_0` (0,6 ГБ).
  Гибридная модель: рекуррентное состояние нельзя откатить, поэтому история только дописывается.
- Флаги: контекст 131072, 2 ячейки (`-np 2`: 0 — разговор, 1 — зрение, дневник, фоновые помощники, песочница),
  KV `q8_0`, `-b 2048 -ub 512`, `-t 6`, MTP `--spec-draft-n-max 2`, рассуждения с бюджетом, temp 0.7.
- Замеры: обработка запроса ~490 ток/с (561 токен за 1,15 с); генерация 44–54 ток/с; MTP принимается
  28–47 % черновиков (средняя длина 1,6–2,0).
- Узкие места: первый ответ после перезапуска ядра ~13 с (пересчёт истории на ~490 ток/с); до первого слова 0,65 с;
  до первого звука 1,4–1,7 с, на командах 1,2 с (короткое «Смотрю погоду»).
- Запасной мозг: Nex-N2.5-mini (`brain/run_brain_nex.sh`, служба `ksenia-brain-nex`).

## Голос — `ksenia-voice-out` :18110, GPU1

- Запуск: `voice-out/run_voice_out.sh`.
- Движок: s2.cpp, наш форк https://github.com/Alexperowo/s2.cpp, ветка `ksenia-perf` (последний коммит 2a79230).
  Наши доработки: KV-кэш и flash attention для Fast-AR, голова на GPU для q8_0, потоковый кодек
  (LRU-кэш графов, асинхронный декодер, `S2_CODEC_TAIL=8` — тяжёлая часть кодека только по новым кадрам,
  46,8 дБ к эталону), GEMM для conv_transpose_1d. Итог — в 2,2 раза быстрее: 27 мс на кадр (46 мс звука).
- Модель: Fish Audio S2 Pro `s2-pro-q8_0.gguf` (5,6 ГБ), голос Маши — `voice-out/voices/masha.s2voice`. Занято 6,4 ГБ.
- Замеры: первый звук 0,6–0,85 с, RTF ~0,6.

## Судья перебиваний — `ksenia-judge` :18150, GPU1

- Запуск: `brain/run_judge.sh`. Движок: llama.cpp основной (`63bef27`).
- Модель: NeoHorse-1-4B `Q4_K_M` (2,7 ГБ), контекст 4096, `--cache-reuse 256`, без рассуждений. Занято 3 ГБ.
- Замеры: 46 из 48 случаев правильно, 0,11 с. Сравнение с другими моделями — `docs/LIVE-MODE-RESEARCH.md`.

## Слух — `ksenia-voice-in` :18120, GPU1

- Запуск: `voice-in/run_voice_in.sh`, настройки — `voice-in/config.json`.
- Распознавание: GigaAM v3 e2e CTC (`gigaam-v3-e2e-ctc`), `asr_device: cuda`. Whisper large-v3-turbo — запасной.
- Отпечаток голоса: WeSpeaker ResNet34 (ONNX). Конец реплики: Smart Turn v3.2 (ONNX, CPU) + правило «висящего слова».
- Занято 1,3 ГБ.

## Ядро и остальное

- Настройки ядра — `core/config.json`, поверх него настройки Александра — `data/settings.json` (не в git).
- Службы — `services/*.service` (совпадают с установленными в `~/.config/systemd/user/`).

## Что не в git

Веса моделей (`~/Models/...`), собранные движки (`~/backend/...`), личные данные (`data/`), секреты
(`secrets/`, `brain/api_key`). Код форка голосового движка — в отдельном репозитории (см. выше).
