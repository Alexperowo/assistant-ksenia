# Живой режим (как реалтайм у ChatGPT) — исследование, 2026-10-08

Цель: говорить с Ксенией без кнопки и сигнала, перебивать её на полуслове, ответ — через ~1 с после конца фразы.

## Чем «реалтайм» отличается от нашего режима сейчас
| | Сейчас | Живой режим |
|---|---|---|
| Начать говорить | клавиша/сигнал | просто говорить |
| Конец фразы | 0,7 с тишины | модель «смысла»: закончил ли человек мысль (~0,2–0,3 с) |
| Перебить Ксению | нельзя (микрофон закрыт, пока она говорит) | заговорил — она замолкает |
| Микрофон | только на время реплики | открыт всё время, нужно подавление эха |
| Ответ после фразы | ~2,4 с | цель ~1–1,5 с |

## Части и что есть свежего (проверено поиском)
1. **Постоянный микрофон + подавление эха.** Без него Ксения слышит саму себя и «перебивает» сама себя.
   - Планшет: браузер Chrome на Android даёт встроенное подавление эха и шума (`echoCancellation`) — готово «из коробки».
   - ПК с наушниками: эха почти нет, но классический Bluetooth при открытом микрофоне уходит в HFP (глухой звук).
2. **LE Audio — ключ для наушников.** JBL Tour One M3 по данным JBL поддерживает LE Audio (LC3). В LE Audio
   микрофон и качественный звук идут одновременно, без провала в HFP. На этом ПК: адаптер MediaTek с Bluetooth 5.3,
   ядро 7.0, BlueZ 5.85, PipeWire 1.6.2 — всё свежее; но профили LE Audio сейчас не включены (в BlueZ это пока
   экспериментальная опция). Нужна проверка: включить и посмотреть, появится ли LC3 у наушников. Это системная
   настройка — только с разрешения Александра, с резервной копией.
3. **Конец фразы по смыслу.** Smart Turn v3 (Pipecat) поддерживает русский, работает на CPU за десятки мс,
   запускается после короткой паузы детектора речи (Silero VAD).
4. **Потоковое распознавание русского** (для перебивания и раннего старта): T-one (Т-Банк, 71M, Apache 2.0, поток
   по 300 мс, быстрый на CPU). Для точного итога — оставить Whisper turbo или GigaAM v3 (Сбер, MIT, сильный русский).
5. **Перебивание (barge-in).** Детектор речи на открытом микрофоне → мгновенно стоп голоса и генерации.
   В историю идёт только то, что Ксения успела СКАЗАТЬ (идея и код были в старой Ксении: `live.py`, «generated/spoken»).
6. **Быстрее ответ.** Начинать думать по частичному тексту, первый кусок голоса короче, кэш мозга уже работает;
   «живые» короткие звуки-заполнители («так…», «ммм») — по желанию.
7. **Готовые каркасы.** Pipecat (BSD): детектор речи, Smart Turn, перебивания, WebRTC для браузера — можно встроить
   наши голос, слух и мозг как модули. Открытых готовых русских систем «всё в одном» с подавлением эха нет
   (ближайшее — демо Rula).
8. **Модели «речь-в-речь»** (Qwen-Omni и т.п.) — не советую: теряем голос Маши, инструменты, характер и
   надёжность русского; тяжелее по видеопамяти.

## Предложение (по шагам)
1. **Живой режим на планшете** (в приложении Fable): открытый микрофон с подавлением эха браузера, детектор речи +
   Smart Turn на шлюзе/ядре, перебивание. Наименьший риск, всё нужное уже есть.
2. **Проверка LE Audio с JBL** (системная настройка, отдельно, с откатом). Если заработает — живой режим в наушниках
   у ПК без провала качества. Если нет — живой режим в наушниках только с HFP-качеством голоса.
3. Потоковое распознавание (T-one) для раннего старта и надёжного перебивания; Whisper/GigaAM — для итога.
4. Решить: свой код (по образцу старого `live.py`) или Pipecat — сделать короткую пробу Pipecat с нашими модулями.
