# Ксения на планшете (PWA)

Планшет (Galaxy Tab S9 Ultra, Chrome) — второй способ говорить с Ксенией: вместо Bluetooth-наушников у компьютера
или вместе с ними. Ответ звучит голосом Ксении на планшете; музыка у компьютера на время разговора приглушается.

## Как устроено

```
планшет (Chrome, PWA) ──HTTPS/WSS──▶ шлюз ksenia-pwa :18140 ──127.0.0.1──▶ ядро :18130, слух :18120
                     ──HTTP──────▶ :18141 (только сертификат и инструкция)
```

- Ядро и слух по-прежнему принимают запросы **только с этого компьютера**. Шлюз — отдельный сервис, он ходит к ним
  по 127.0.0.1 сам.
- Вход: код из 6 цифр один раз, потом долгая сессия (180 дней, cookie HttpOnly + Secure + SameSite=Strict).
  Код хранится в `data/pwa/pin`, его же Ксения произносит у компьютера по кнопке «Произнести код на компьютере».
- Ограничение попыток: 5 неверных кодов с одного адреса за 10 минут, 20 со всех адресов за час.
- Только домашняя сеть (адрес планшета — частный), только свои имена в адресе (защита от DNS rebinding),
  запросы и WebSocket — только со своей страницы (проверка Origin).
- Запись: браузер пишет 16 кГц моно в WAV сам (AudioWorklet). MediaRecorder в Chrome умеет только WebM/MP4,
  а слух читает WAV — поэтому без перекодирования и без ffmpeg.

## Установка на компьютере (один раз)

```bash
cd ~/Agents/Ksenia
pwa/make-certs.sh                  # свой корневой сертификат + сертификат шлюза для адресов компьютера
cp services/ksenia-pwa.service ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable --now ksenia-pwa
cat data/pwa/pin                   # код входа (или кнопка «Произнести код» на планшете)
```

Если адрес компьютера в сети сменился — снова `pwa/make-certs.sh` и `systemctl --user restart ksenia-pwa`.
Корневой сертификат при этом не меняется, на планшете ничего переустанавливать не нужно.
Свой адрес или имя можно добавить: `pwa/make-certs.sh 192.168.0.14 ksenia.lan`.

Порт 18140 и 18141 должны быть открыты для домашней сети, если включён межсетевой экран
(например, `sudo ufw allow from 192.168.0.0/16 to any port 18140:18141 proto tcp`).

## На планшете (один раз)

1. В Chrome открыть `http://<адрес компьютера>:18141/` (адрес печатает `make-certs.sh`).
2. Нажать «Скачать сертификат Ксении».
3. Настройки → «Безопасность и конфиденциальность» → «Другие параметры безопасности» →
   «Установить из памяти устройства» → «Сертификат ЦС» → согласиться → выбрать `ksenia-ca.crt` в «Загрузках».
   (Можно найти через поиск настроек по слову «сертификат». Названия пунктов на One UI могут немного отличаться.)
4. Вернуться в Chrome, нажать «Открыть Ксению» (`https://<адрес>:18140/`).
5. Нажать «Произнести код на компьютере», ввести код, «Войти».
6. Меню Chrome (три точки) → «Добавить на главный экран»: Ксения станет отдельным приложением.

## Как пользоваться

- **«Говорить»** — сигнал, говорите; Ксения сама поймёт паузу (около 0,8 с). Нажатие во время ответа перебивает её.
  В настройках можно выбрать «Держу кнопку, пока говорю».
- **«Стоп»** — замолчать.
- **«Да» / «Нет»** — появляются, когда Ксения спрашивает «Отправить?» или «Нажать …?». Решение всё равно
  принимает ядро, кнопки просто говорят «да» или «нет».
- Состояния: «Слушаю», «Думаю», «Говорю», «Нет связи с компьютером» — словом, значком своей формы, звуковым
  сигналом и вибрацией. Про связь планшет говорит своим голосом (голос Ксении в это время недоступен).
- Разговор: последняя пара «Вы сказали / Ксения» — крупно сверху, ниже история, новые реплики сверху
  (видно сразу, без прокрутки, и с экранной лупой).
- Экран не гаснет, пока приложение открыто.
