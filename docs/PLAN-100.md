## Решения Александра (2026-10-09)

- Telegram — да (вход вместе, по коду). YouTube — через VPN, Ксения управляет им сама; **VPN для всей системы
  мешает другим программам** — Ксении нужен прокси только для своего браузера, а не туннель для всего компьютера.
- Файлы — где их положит Ксения; к компьютеру Александр подходит редко.
- Будильника нет (на ночь компьютер выключен) — только напоминания. Календарь не нужен, только дни недели.
- Уведомления — по вопросу «что пришло?», но от выбранных людей и мест — сразу. Правило задаётся голосом
  («от Курьера говори сразу») и хранится в памяти.
- Характер: с юмором, дерзкая, любит новые технологии и новости нейросетей, может не соглашаться, у неё своё
  мнение — «безбашенная подруга», а не копия Александра.
- Переезд на чистую систему — отложен.
