# Черновики остановленных помощников

командами), поэтому сохранено то, что от них осталось.

## A2 — разговор, живой режим, центр управления
- Успел написать одну проверку: `probes/agent_a2/lo.py` — пытается обойти защиту ядра «только с этого
  компьютера» (`local_only` в core/core.py) подменой заголовков Host и Origin.
- Результат запуска (2026-10-10, на ветке аудита): поддельные Host (`0.0.0.0`, `127.1`, `127.0.0.2`,
  `127.0.0.1:18130@evil.com`) и чужие Origin (`https://evil.example`, `http://127.0.0.1.evil.com`) отклоняются (403).
  **Пропускаются** запросы с Origin другого локального порта: `http://127.0.0.1:8888`, `http://[::1]:3000`.
  Значит, страница любой другой программы с веб-интерфейсом на этом компьютере может управлять ядром
  (POST /say, /talk, /control/act). Риск низкий-средний; исправление — пускать только Origin своего шлюза
  (:18142) или без Origin.
- Заголовки X-Forwarded-* ядро не использует — подмена ничего не даёт.
