# Аудит 4 — материалы

Незаконченный аудит по заданию `docs/task-fable-4-audit.md` (остановлен по лимиту 2026-10-09).

- `../REVIEW-4-draft.md` — сводка всех находок по одной строке, со статусом.
- `reports/` — полные отчёты помощников, как они их прислали (сценарии, строки, проверки, варианты исправлений):
  - `B-confirmations-tools.md` — подтверждения, инструменты, внедрение команд, данные;
  - `C-system-settings-network.md` — терминал, настройки, Wi-Fi, сеть, обход блокировок, оплата;
  - `A1-core-turn-history.md` — ход ядра, история мозга, песочница, напоминания, текст для речи;
  - `F-services-prompts.md` — службы, сон и пробуждение, логи, подсказки и фильтры речи;
  - `D-hearing-voice.md` — слух, отпечаток голоса, наушники, озвучка.
- `probes/` — скрипты, которыми помощники проверяли находки запуском кода (подделки, без железа).
  Запуск: из корня репозитория, python из окружения тестов; часть скриптов ожидает копию репозитория рядом —
  пути внутри поправить под себя.

каждого отчёта. Код с тех пор менялся: искать по имени функции.
