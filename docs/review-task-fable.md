# Задание для облачного ревью (Fable 5.1)

Репозиторий: Alexperowo/assistant-ksenia, ветка `main` (Linux-версия Ксении, альфа).
Прочитай README.md, ROADMAP.md, ANALYSIS.md, затем код в `core/`, `voice-in/`, `voice-out/`, `brain/`, `services/`.

## Контекст и жёсткие ограничения
- В облаке нет железа проекта (2 GPU, Bluetooth-наушники, KDE/Wayland, модели). Живые проверки делаются локально.
  Не пытайся запускать сервисы и скачивать модели.
- НЕ меняй без явной причины и пометки в отчёте:
  - историю разговора «только дописывать» (мозг — гибридная модель Nex: любое изменение начала запроса
    = полный пересчёт контекста; время пишется в реплику пользователя и хранится в истории как есть);
  - логику Bluetooth HFP/A2DP в `voice-in` (сигнал с разгоном 350 мс, игнор первых 0,35 с, окно детектора речи,
    ожидание возврата A2DP до ответа) — всё это подобрано по живым замерам;
  - распределение по видеокартам и порты сервисов;
  - характер в `core/prompts/persona.md` (можно предлагать правки отдельным списком).
- Никаких секретов в коде; ключи лежат в `secrets/` и `brain/api_key` (исключены из git).

## Что сделать
1. **Ревью кода** на ошибки: корректность, гонки и отмена в asyncio (Speaker, Conversation, очередь озвучки,
   фоновые задачи музыки), утечки процессов (pacat, parec, mpv), обработка сбоев сети/сервисов,
   безопасность (subprocess, пути, внешние данные из радио/Яндекса/OCR как недоверенный ввод),
   поведение при пустых/битых ответах сервера, кодировки.
2. **Тесты** (pytest, без сети и без железа) для чистых функций и логики с моками:
   `split_first_sentence`, `clean_for_speech`, `split_for_reading`, `is_goodbye`, `budget_for`/ACTION_PATTERNS,
   окно истории `_window`, разбор потоковых tool_calls, фильтр станций в music, `_chunk`/`_ocr`-постобработка в screen,
   детектор речи `record_utterance` на синтетическом сигнале (с моком parec).
3. **Отчёт** `docs/REVIEW.md`: находки по убыванию важности (файл:строка, сценарий сбоя, предложение),
   отдельно — что проверено и не вызвало вопросов.
4. Исправления — **в отдельной ветке и pull request**, не в `main`. Небольшие независимые коммиты.

Пиши отчёт по-русски, коротко и конкретно.
