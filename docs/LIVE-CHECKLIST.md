# Живые проверки с Александром

То, что нельзя проверить без голоса, наушников и планшета. Порядок — от простого к сложному.
Каждую проверку агент подсказывает в наушники; замечания — голосом: «Заметка: …» (пишется в `data/agent_notes.md`).
Отметки: [ ] не проверено, [x] прошло, [!] есть замечания.

## 1. Каждый день
- [ ] Включил компьютер, надел наушники — Ксения молчит (всё в порядке) или сама говорит, что не так.
- [ ] Наушники не подключились или нет звука — «Почини звук», Ксения переподключает сама.
- [ ] «Режим музыки» и «режим разговора» — переключение голосом, звук возвращается через 10–20 с.

## 2. Разговор
- [ ] Касание наушников — разговор; «пока» — конец. Ctrl+Alt+K — то же с клавиатуры.
- [ ] Говорю с паузами и «э-э» — не обрывает.
- [ ] «Расскажи историю…» — поддакиваю «ага», «серьёзно?» — рассказ продолжается.
- [ ] Перебиваю новой просьбой — замолкает и отвечает на новое; «продолжай» — возвращается к рассказу.
- [ ] «Стоп» / касание во время речи — замолкает сразу.
- [ ] Рядом говорит жена или дочка — Ксения не принимает их слова за мои, «подожди» чужим голосом её не останавливает.
- [ ] Звонок на телефон — Ксения замолкает.
- [ ] Ночью (после 23) говорит тише.

## 3. Голос Александра
- [ ] «Запиши мой голос» — 5 фраз, потом «да» принимается только моим голосом.
- [ ] «Гостевой режим» / «слушай только меня».

## 4. Руки
- [ ] Радио, песня в Яндекс Музыке, «Моя волна», аудиокнига (выбор чтеца, «продолжи книгу»).
- [ ] YouTube: «включи на YouTube…» (звук), «покажи видео…» (на весь экран).
- [ ] Пауза, громче, тише, следующая — голосом и кнопками наушников.
- [ ] Напоминание через 2 минуты — звучит в наушниках и в колонках.
- [ ] «Напечатай…» в открытом поле (диктовка).
- [ ] «Что нового в загрузках?», «прочитай второй», «удали в корзину» — переспрашивает «да».
- [ ] Яркость, громкость, тема; «к какой сети Wi-Fi я подключён?».
- [ ] ВКонтакте: «кто писал?», «прочитай от…», «напиши… : …» → «Отправить?» → «да».
- [ ] «Сообщай сразу, если напишет…» — потом приходит сообщение, Ксения говорит сама.

## 5. Глаза
- [ ] «Что на экране?», «прочитай окно», «что под курсором?», «нажми надпись…».
- [ ] Лупа: «увеличь», «уменьши».

## 6. Планшет
- [ ] Сертификат: `http://<IP компьютера>:18141/` → установить; приложение `https://<IP>:18140/` → вход по коду.
- [ ] «Говорить» — одна фраза; «Живой разговор» — как в наушниках.
- [ ] «Что передо мной?» — этикетка, письмо.
- [ ] «Да / Нет» на подтверждение.
- [ ] Вкладки «Управление», «Память», «Состояние» с TalkBack: всё ли зачитывается, крупно ли.

## 7. Характер и развлечения
- [ ] «Что ты умеешь?» — коротко и понятно; «расскажи про музыку» — раздел.
- [ ] Загадка, викторина, «города», «угадай песню», сказка для дочек.
- [ ] Спорю с ней — у неё своё мнение; шутки не повторяются.

## Автопроверка без голоса (делает агент)
`.venv/bin/python tools-scripts/selftest_text.py` — тихо, в песочнице: время, погода, музыка, память,
напоминания, файлы, наушники, самопроверка, новости, ВКонтакте, справка, личность.
