# Конфигурация

## Слои

`config/default.json` входит в дистрибутив и содержит безопасные переносимые значения. `config/user.json` содержит только отличия конкретного компьютера. При загрузке словари глубоко объединяются: значение пользователя обычно переопределяет соответствующее значение по умолчанию, остальные поля сохраняются. Исключение — встроенный минимум безопасности: личная настройка не может заменить обязательное подтверждение на `allow`, разрешить финансовое действие или вывести файловый корень за `developer.workspace_dir`.

Следствия:

- обновление `default.json` не должно стирать личные пути;
- `user.json` не нужно копировать целиком из примера;
- неизвестное или устаревшее личное поле нужно мигрировать осознанно;
- `user.json` не включается в Git и релизный архив.

## Основные разделы

| Раздел | Назначение |
|---|---|
| `assistant` | имя, роль по умолчанию, голосовые статусы |
| `paths` | `llama-server`, модели и runtime |
| `server` | только loopback, порт и время запуска |
| `voice` | Python, Vosk, Whisper, устройство, паузы и тайм-ауты |
| `browser` | Chromium и постоянный профиль |
| `models` | конкретные GGUF-профили и аргументы `llama.cpp` |
| `capability_roles` | соответствие функций профилям моделей |
| `agent` | пределы шагов, инструментов, подтверждений и голосовых статусов |
| `generation`, `routing` | лимиты ответа, плана и исследования |
| `memory`, `rag` | сжатие, постоянная память и индекс |
| `permissions` | allow/confirm/deny для каждого класса действий |
| `developer` | рабочая область и разрешённые программы |
| `lan` | домашний интерфейс и порт панели |

## Роль и модель — не одно и то же

`assistant`, `researcher`, `developer`, `heavy_brain` — функциональные роли. `developer`, `developer_qwopus`, `planner` в разделе `models` — исторические идентификаторы профилей GGUF. Название профиля не должно использоваться как доказательство его назначения; смотрите `capability_roles`.

## Пример личного пути к модели

```json
{
  "paths": {
    "models_dir": "D:/AI/Models"
  },
  "models": {
    "developer_qwopus": {
      "path": "D:/AI/Models/Qwopus3.5-9B-Coder-MTP-Q6_K.gguf",
      "enabled": true
    }
  }
}
```

Путь может быть абсолютным. Большой файл не копируется в проект.

## Контекст и память

Размер контекста — верхняя ёмкость, а не цель заполнять её целиком. Для 64K используются `--cache-type-k q8_0` и `--cache-type-v q5_0`, но модель, MTP и буферы всё равно требуют отдельного измерения. Сжатие начинается до полного окна; RAG передаёт только релевантные фрагменты. `rag.min_vector_similarity` по умолчанию равен `0.3`: ниже него чисто смысловой кандидат отбрасывается, но найденное FTS5 лексическое совпадение остаётся доступным. Допустимы значения от 0 до 1.

Стартовые значения для другого компьютера находятся в `hardware-profiles.json`. Скрипт оборудования только рекомендует профиль и не меняет рабочие настройки автоматически.

## Ограничение подтверждений

`agent.max_confirmation_requests` задаёт число самостоятельных вопросов подтверждения внутри одной задачи. Значение по умолчанию — 4, а код всегда ограничивает его диапазоном 1–8. Связанные обратимые действия, покрытые уже выданным разрешением, не создают нового вопроса. Запуск проектных тестов считается исполнением кода и также требует согласия. После достижения предела Ксения сообщает об остановке повторных подтверждений и завершает задачу без новых инструментов.

## Рассуждение и длина ответа

Поддерживаются уровни `off`, `brief`, `normal`, `deep`. Они меняют режим и ограниченный reasoning budget, но не дают модели бесконечно размышлять. Пользовательский предел ответа — 1024, 4096 или 8192 токенов; маршрутизатор отдельно ограничивает план и каждый этап исследования.

## Устройства голоса

Bluetooth-имя и индекс нестабильны между переподключениями. Конфигурация хранит предпочтение, а аудиомодуль проверяет реальные режимы устройства. Не хардкодьте индекс, полученный на другом компьютере. При отсутствии устройства голосовой агент должен использовать backoff и оставаться управляемым горячей клавишей остановки.

## Секреты

PIN LAN и ключи локального API создаются в `runtime`, не в `default.json`. Пароли сайтов вводятся Александром вручную в отдельном профиле браузера. В конфигурации нельзя хранить токены в URL, командной строке или документации.

## Проверка изменений

После ручного изменения JSON:

1. проверить синтаксис через `AUDIT.cmd`;
2. убедиться, что Doctor показывает фактические пути;
3. перезапустить только затронутую службу;
4. проверить журнал и живой сценарий;
5. не считать отсутствие исключения доказательством правильного GPU-offload или качества модели.
