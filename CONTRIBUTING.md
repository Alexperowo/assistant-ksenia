# Как помочь проекту

Спасибо за интерес к Ксении. Проект находится на стадии сырой альфа-версии: интерфейсы, конфигурация и архитектура ещё могут меняться.

## Перед началом

1. Прочитайте [AGENTS.md](AGENTS.md), [архитектуру](docs/ARCHITECTURE.md) и [правила безопасности](docs/SECURITY.md).
2. Для ошибки сначала проверьте существующие Issues.
3. Не публикуйте модели, личные настройки, журналы, голосовые записи, браузерные профили, PIN, ключи или содержимое пользовательских файлов.
4. Для уязвимости используйте приватный отчёт по инструкции из [SECURITY.md](SECURITY.md), а не публичный Issue.

## Изменения

- Одна ветка и один pull request должны решать одну логическую задачу.
- Поведение, доступность или формат данных сопровождаются тестом и документацией.
- Изменение `llama.cpp`, голосовых библиотек или модели требует зафиксированных версий, контрольных сумм и живого benchmark.
- Новое действие компьютера получает явную политику `allow`, `confirm` или `deny`.
- Текст интерфейса должен быть понятен без зрения и хорошо звучать через TTS.

## Проверка

Быстрый набор не требует моделей или GPU:

```powershell
python scripts\run_test_suite.py --order-audit
python scripts\validate_release.py
```

На настроенном компьютере дополнительно выполняется:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\check.ps1
```

Физический микрофон, динамик, Bluetooth-кнопка и настоящие внешние действия проверяются вручную и никогда не имитируются без согласия пользователя.
