# История изменений

- Performance: реальная голосовая trace отделила быстрые стадии (открытие микрофона 0,9 с, финальный STT 0,7 с, загрузка Laguna 9,1 с) от холодной оценки полного agent prompt, где первый токен не появился за 93 с.
- Benchmark: одинаковый cold/warm A/B Laguna на 16K и 96K показал почти одинаковый холодный TTFT полного 2215-token tool prefix — 64,34 и 63,85 с. Повтор с 2221 cached tokens занял 1,66 и 1,85 с; 16K сэкономил память, но не устранил bottleneck.
- Fixed: короткая реплика без запроса внешнего действия теперь относится к стабильному `CHAT`-профилю без 20 tool schemas. Команды, research и длинные задачи сохраняют прежние маршруты и Permission Broker.
- Fixed: пустой `voice.wake_device` больше не превращает обычный запуск в техническую настройку: Ксения сама выбирает и реально открывает речевой Windows endpoint, отбрасывая Stereo Mix, loopback и line input. Ручной селектор остался строгим override и не переходит к другой гарнитуре.
- Verified: без сохранённого selector живой desktop path сам открыл Tour One M3, записал 7,33 с и распознал русскую фразу на CUDA за 0,7 с. Sense Pro в тот же момент был виден, но не открывался и не был выбран.
- Fixed: живая голосовая проверка нашла конфликт поля `source` с сигнатурой performance milestone, из-за которого падал stop-monitor. Идентификационные аргументы diagnostics сделаны positional-only, а domain field закреплён регрессией.
- Added: мастер микрофона показывает входы, выходы и текущий Windows default без открытия output stream. Обычная речь пока продолжает следовать маршруту Windows; мастер не имитирует ещё не готовый output selector.
- Changed: все доступные Silero v5 опции русского ударения, омографов и `ё` закреплены явно. Это защищает от дрейфа defaults, но не выдаётся за полный словарь произношения.
- Tests: быстрый слой увеличен до 413 уникальных тестов. Полный `check.ps1` 1 сентября прошёл 413/413, три shuffled-порядка, release/dependency/Doctor/LAN, живую Laguna 96K за 1,329 с и Silero→Whisper CUDA с `landmark_recall=1.0`; RAG явно пропущен как выключенный.

- Fixed: при нескольких аудиовходах Ксения теперь всегда требует устойчивый `voice.wake_device`, даже если Windows назначила default: на реальной машине default оказался Stereo Mix. Несовпавший селектор больше не переходит к произвольной другой гарнитуре; список очищает драйверный шум в имени, а личный выбор JBL хранится только в исключённом `config/user.json`.
- Tests: быстрый слой увеличен до 408 уникальных тестов; добавлены регрессии Windows default с несколькими входами, отсутствующего селектора, сохранённого выбора, недоступного endpoint и доступного голосового указания на ярлык настройки.
- Fixed: мастер микрофона больше не принимает присутствие имени в PortAudio за работоспособность: перед атомарным сохранением выполняется настоящий open/close probe, а драйверный отказ остаётся в диагностике и не меняет личную настройку.
- Verified: полный `check.ps1` прошёл 408/408, три перемешанных порядка, release/dependency/Doctor/LAN и Silero→Whisper CUDA с `landmark_recall=1.0`; LLM и RAG явно пропущены как неактивные. Реальный START/STOP отдельно обнаружил недоступные Bluetooth WDM-KS endpoints и не был ложно засчитан как работающий микрофон.

Все заметные изменения пользовательского поведения, форматов данных, зависимостей и требований оборудования записываются здесь. Подробные замеры конкретного компьютера остаются в `docs/AUDIT.md`.

- Tests: добавлены ещё двадцать девять сценариев Live, Vosk-partials, определения конца реплики, потоковой отмены, строгой Silero-очереди, безопасного префикса, памяти, журналов, приватности и конфигурации; быстрый набор вырос с 228 до 257 тестов.
- Tests: ещё двенадцать контрактов довели быстрый набор до 269: семантические профили, поиск артефактов, model/draft/projector supply-chain, запрет модельного/машинного хардкода, сохранение личной конфигурации, Windows PowerShell resolver, очистка stale-state и fail-closed auxiliary-size gate.
- Миграция вручную не требуется: старые журналы задач получают пустые новые поля при чтении. Ornith остаётся выключенным по результату A/B; команды разработки намеренно недоступны в безопасной конфигурации до появления ОС-песочницы; Live — до AEC-приёмки. Новым рабочим профилям требуется отдельный штатный live-gate в свободное GPU-окно.

- Added: локальная одноразовая «Доверенная задача» по явному согласованию Александра — один запрос без повторных подтверждений, горячая клавиша `Control + Alt + D`, полное голосовое предупреждение, 30-минутный срок до начала и автоматическое восстановление обычного режима.
- Security: доверенная задача атомарно достаётся только одному запросу, расходуется также при ошибке/отмене, не переживает перезагрузку и не ослабляет финансовый запрет, секреты, `workspace`, защищённые процессы, сетевые фильтры или запрет shell; модель, голос и LAN не могут её включить.
- Security: личная конфигурация больше не может ослабить обязательные подтверждения, включая запуск тестового кода, финансовый запрет или расширить файловые корни за пределы рабочей папки.
- Changed: параллельное исследование сохраняет порядок запросов и источников независимо от скорости ответов сайтов.
- Changed: RAG получил порог чисто смыслового совпадения, стабильную сортировку равных кандидатов и явный результат `no_match` вместо случайного фрагмента.
- Security: одна задача по умолчанию задаёт не более четырёх вопросов подтверждения; жёсткий программный потолок — восемь.
- Security: исторический промежуточный pin `setuptools 78.1.1` закрыл GHSA-5rjg-fvgr-3xxf до появления совместимого обновления полного CUDA-контура.
- Security: официальные GitHub Actions обновлены до checkout 7.0.1 и setup-python 7.0.0 и закреплены полными commit SHA вместо плавающих major-тегов.
- Tests: после прежних восьми сценариев добавлено ещё 18 проверок доверенной задачи; быстрый набор вырос до 217 тестов, живой RAG — до пяти запросов.
