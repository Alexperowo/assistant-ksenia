# История изменений

Все заметные изменения пользовательского поведения, форматов данных, зависимостей и требований оборудования записываются здесь. Подробные замеры конкретного компьютера остаются в `docs/AUDIT.md`.

## Не выпущено — 28 августа 2026

- Security: `pip`, `setuptools` и CUDA Torch обновлены до проверенных `26.2.1`, `84.0.0` и `2.13.0+cu126`; закрыты GHSA-h35f-9h28-mq5c, GHSA-rrmf-rvhw-rf47 и все найденные OSV-совпадения старого pip. CUDA index и путь Torch lock перенесены в машинно проверяемую конфигурацию вместо варианта, зашитого в PowerShell.
- Fixed: все 14 ярлыков Ксении закреплены единым контрактом; CMD-обёртки возвращают реальный exit code, установщик очищает устаревшие hotkeys и перепроверяет target/working directory после сохранения `.lnk`.
- Docs: добавлен датированный документ передачи с честным статусом Live/AEC, фактическими ярлыками, новым локальным модельным инвентарём, отсутствующими reasoning-артефактами и безопасным порядком продолжения.

- Security: перед первым запуском каждого GGUF проверяются размер и полный SHA-256; результат кэшируется только для неизменившегося file identity/stat, а любое изменение заставляет пересчитать хэш. Символические ссылки моделей отклоняются до разрешения пути.
- Security: активное управление браузером и Windows по умолчанию скрыто и отключено; строковые значения вроде `"false"` больше не считаются истинными. Windows-ввод останавливается fail-closed, если активное или целевое окно нельзя точно определить.
- Fixed: чтение потока `llama.cpp`, включая tool-call и tokenizer-запрос, стало отменяемым во время сетевого зависания; checkpoint проверяется примерно каждые 100 мс, а фрагменты tool-call собираются обратно до исполнения.
- Fixed: постоянный Silero worker принимает запросы только после явного события `ready`; TTS-модель загружается из закреплённого локального файла с проверкой размера/SHA-256 без mutable manifest или runtime-download. Остановка больше не может проиграть гонку запуску аудиопроцесса или допустить новую фразу после stop.
- Fixed: фоновый listener команды «стоп» и голосовое подтверждение передают единственный микрофон через явный gate, не открывая два audio worker одновременно.
- Fixed: конфигурация, PID/state, API-ключ, LAN PIN, модельный integrity-cache, журнал отмены и файловые изменения используют уникальную атомарную запись и межпроцессную блокировку; операции изменения и их undo-record составляют одну сериализованную транзакцию.
- Changed: выключенный `candidate` исправлен на действительно запрошенный `conFIGur8tor/ornith15-35b-a3b-apex-mtp-fixed`, commit `63518f71...`, файл `ornith15-trained-head.gguf`; MTP объявлен, но профиль не включается до собственного локального A/B.
- Tests: быстрый слой содержит 326 уникальных тестов без пропусков; полный прогон и три перемешанных порядка проходят без warnings.
- Security: `write_workspace_file` теперь только создаёт новый файл и на уровне ОС не может перезаписать существующий путь; изменение существующего текста допускается только через `replace_in_workspace_file` с ровно одним совпадением.
- Fixed: удалён эксперимент с исчезновением read/search-инструментов после лимита исследования. На реальной задаче Laguna подменила намерение чтения доступной записью; пять ошибочных изменений были полностью отменены журналом, а рабочая копия целевого проекта проверена как чистая.
- Tests: реальная разработческая проверка дополнена регрессией «повторная целиковая запись получает `existing_file_requires_replace`, исходный текст не меняется» без увеличения формального числа тестов.
- Changed: прежние модельные профили заменены семантическим каталогом `generalist`/`reasoning`/`candidate`: Laguna XS 2.1 APEX I-Quality + DFlash, Qwen 3.8 27B Opus Distill v2 + MTP/mmproj и выключенный Ornith 1.5 35B-A3B. Функциональные роли больше не зависят от имени семейства.
- Changed: `llama.cpp` обновлён стадийно до официального b10241, commit `9bd4c09ea`, CUDA 12.4; оба архива закреплены официально проверенными SHA-256, прежний движок сохранён для отката.
- Added: каждый профиль объявляет независимые `model`/`draft`/`projector`-артефакты с полным commit, размером и SHA-256; локальные файлы разрешаются через настраиваемые каталоги поиска.
- Fixed: удалён отсутствующий в b10241 аргумент `--ctx-size-draft`; размеры draft/projector теперь отклоняются до запуска процесса так же, как размер основной модели.
- Fixed: настройка путей больше не перезаписывает `config/user.json`; личные голосовые, браузерные и модельные параметры сохраняются атомарно.
- Changed: фиксированные каталоги Python и ветвления по модельным названиям удалены из Python/PowerShell runtime. Общий resolver использует параметр, окружение, личную конфигурацию и переносимые относительные корни.
- Benchmark: прежний SC117 Ornith-артефакт прошёл 7/7 сценариев, но MTP дал 51,80 против 78,68 токена/с без MTP и 19,9% acceptance. Эти результаты сохранены только как исторические и не относятся к новому fixed-head кандидату conFIGur8tor.
- Added: отдельный выключенный профиль `candidate` для `conFIGur8tor/ornith15-35b-a3b-apex-mtp-fixed` с полным commit, исходным именем, точным размером и SHA-256.
- Added: воспроизводимая команда загрузки и проверки GGUF отвергает плавающие revision и вложенные имена, не использует пользовательский Hugging Face token и принимает файл только после полного SHA-256.
- Fixed: чтение заголовка активного окна теперь корректно помечает локальные данные, поэтому следующий внешний веб-запрос снова требует подтверждения и не создаёт канал утечки.
- Fixed: benchmark модели-кандидата может испытать выключенный профиль во временной копии конфигурации, не включая его для обычной работы.
- Security: команды разработчика теперь по умолчанию заблокированы fail-closed до подключения проверенной ОС-песочницы; прежний host-runner требует отдельного точного признания риска и не выдаётся за sandbox.
- Security: ошибка загрузки модели больше не переносит в пользовательский текст URL, токен или другие детали исключения сетевой библиотеки.
- Tests: добавлены одиннадцать регрессионных сценариев для активного окна, профиля Ornith, supply-chain моделей и безопасного backend команд; быстрый набор вырос с 217 до 228 тестов.
- Added: отдельный Live v1-контур (`LiveSession`, `StreamingTTS`, `BargeInController`, `ConversationCoordinator`) получает безопасные дельты итогового ответа, подтверждает окончание каждой TTS-фразы и отменяет генерацию до остановки аудио. Детерминированный `HybridTurnDetector` получает потоковые Vosk-partials во время записи, сочетает их с VAD-состоянием и паузой, а качественный финальный текст по-прежнему формирует faster-whisper.
- Changed: долговечная задача хранит `generated_answer` и `spoken_answer` отдельно; разговорная память Live фиксирует только непрерывный префикс полностью завершённых фраз. Поздние и переставленные callbacks не могут добавить отменённый текст.
- Security: технический префикс tool-call удерживается до распознавания и не передаётся потоковому TTS. `live.enabled` остаётся `false` до живой проверки AEC, микрофона и акустического эха.
- Tests: добавлены ещё двадцать девять сценариев Live, Vosk-partials, определения конца реплики, потоковой отмены, строгой Silero-очереди, безопасного префикса, памяти, журналов, приватности и конфигурации; быстрый набор вырос с 228 до 257 тестов.
- Tests: ещё двенадцать контрактов довели быстрый набор до 269: семантические профили, поиск артефактов, model/draft/projector supply-chain, запрет модельного/машинного хардкода, сохранение личной конфигурации, Windows PowerShell resolver, очистка stale-state и fail-closed auxiliary-size gate.
- Миграция вручную не требуется: старые журналы задач получают пустые новые поля при чтении. Ornith остаётся выключенным по результату A/B; команды разработки намеренно недоступны в безопасной конфигурации до появления ОС-песочницы; Live — до AEC-приёмки. Новым рабочим профилям требуется отдельный штатный live-gate в свободное GPU-окно.

- Added: локальная одноразовая «Доверенная задача» по явному согласованию Александра — один запрос без повторных подтверждений, горячая клавиша `Control + Alt + D`, полное голосовое предупреждение, 30-минутный срок до начала и автоматическое восстановление обычного режима.
- Security: доверенная задача атомарно достаётся только одному запросу, расходуется также при ошибке/отмене, не переживает перезагрузку и не ослабляет финансовый запрет, секреты, `workspace`, защищённые процессы, сетевые фильтры или запрет shell; модель, голос и LAN не могут её включить.
- Security: личная конфигурация больше не может ослабить обязательные подтверждения, включая запуск тестового кода, финансовый запрет или расширить файловые корни за пределы рабочей папки.
- Changed: параллельное исследование сохраняет порядок запросов и источников независимо от скорости ответов сайтов.
- Changed: RAG получил порог чисто смыслового совпадения, стабильную сортировку равных кандидатов и явный результат `no_match` вместо случайного фрагмента.
- Security: одна задача по умолчанию задаёт не более четырёх вопросов подтверждения; жёсткий программный потолок — восемь.
- Security: исторический промежуточный pin `setuptools 78.1.1` закрыл GHSA-5rjg-fvgr-3xxf до появления совместимого обновления полного CUDA-контура.
- Security: официальные GitHub Actions обновлены до checkout 7.0.1 и setup-python 7.0.0 и закреплены полными commit SHA вместо плавающих major-тегов.
- Tests: после прежних восьми сценариев добавлено ещё 18 проверок доверенной задачи; быстрый набор вырос до 217 тестов, живой RAG — до пяти запросов.
- Действия Александра и миграция данных не требуются.

## 0.1.0 — 11 августа 2026

- Создан локальный голосовой дворецкий-разработчик для Windows 11 и слабовидящего пользователя.
- Реализованы четыре роли, одна активная GGUF-модель, 64K, MTP, reasoning budget и управляемая длина ответа.
- Добавлены Vosk wake/stop, faster-whisper, Silero Xenia, Bluetooth-защита начала речи и медиакнопка.
- Добавлены долговечные задачи, сжатая история, подтверждённые факты, межролевая память и гибридный RAG.
- Добавлены web research, Chromium isolation, Windows Automation, подтверждения, журнал изменений и LAN-панель.
- Проведён аудит безопасности, журналов и доступности; создано 191 автоматическое испытание и живые gates.
- Добавлены `AGENTS.md`, полный комплект документации передачи, lock-файлы Python, аппаратные профили и машинный release manifest.
- Добавлены безопасные `INSTALL.cmd`, `UPDATE.cmd`, `ROLLBACK-UPDATE.cmd`, сборка и проверка чистого ZIP без моделей/личных данных.
- Настройки по умолчанию очищены от абсолютных путей конкретного компьютера; реальные пути Александра остаются только в исключённом из архива `config/user.json`.
- Подготовлено публичное оформление сырой alpha-версии: эмблема в README, MIT, GitHub Actions, issue/PR templates, CONTRIBUTING и политика приватного сообщения об уязвимостях.

## Правила будущих записей

- `Added`, `Changed`, `Fixed`, `Security`, `Migration`, `Removed` описываются отдельно.
- Указывается, требуется ли действие Александра.
- Изменение схемы данных получает инструкцию резервного копирования и отката.
- Обновление модели содержит benchmark, а обновление движка — release/commit и compatibility gate.
