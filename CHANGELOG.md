# История изменений

Все заметные изменения пользовательского поведения, форматов данных, зависимостей и требований оборудования записываются здесь. Подробные замеры конкретного компьютера остаются в `docs/AUDIT.md`.

## 0.1.0 — 11 августа 2026

- Создан локальный голосовой дворецкий-разработчик для Windows 11 и слабовидящего пользователя.
- Реализованы четыре роли, одна активная GGUF-модель, 64K, MTP, reasoning budget и управляемая длина ответа.
- Добавлены Vosk wake/stop, faster-whisper, Silero Xenia, Bluetooth-защита начала речи и медиакнопка.
- Добавлены долговечные задачи, сжатая история, подтверждённые факты, межролевая память и гибридный RAG.
- Добавлены web research, Chromium isolation, Windows Automation, подтверждения, журнал изменений и LAN-панель.
- Проведён аудит безопасности, журналов и доступности; создано 191 автоматическое испытание и живые gates.
- Добавлены `AGENTS.md`, полный комплект документации передачи, lock-файлы Python, аппаратные профили и машинный release manifest.
- Добавлены безопасные `INSTALL.cmd`, `UPDATE.cmd`, `ROLLBACK-UPDATE.cmd`, сборка и проверка чистого ZIP без моделей/личных данных.
- Настройки по умолчанию очищены от абсолютных путей конкретного компьютера; реальные пути Александра остаются только в исключённом из архива `config/user.json`.
- Подготовлено публичное оформление сырой alpha-версии: эмблема в README, MIT, GitHub Actions, issue/PR templates, CONTRIBUTING и политика приватного сообщения об уязвимостях.

## Правила будущих записей

- `Added`, `Changed`, `Fixed`, `Security`, `Migration`, `Removed` описываются отдельно.
- Указывается, требуется ли действие Александра.
- Изменение схемы данных получает инструкцию резервного копирования и отката.
- Обновление модели содержит benchmark, а обновление движка — release/commit и compatibility gate.
